# Mostly Human — website

De one-page website van Mostly Human, een klein marketingbureau uit Mechelen.

Alles zit in één bestand: `index.html` (HTML, CSS en een paar regels JavaScript, geen build-stap).
De afbeeldingen (alien-logo en wordmark) staan op Wix Media en worden via `static.wixstatic.com` geladen.

## Online zetten

Upload `index.html` naar de webroot van de hosting (bij Combell: `www/`). Meer is niet nodig.

## Lokaal bekijken

Open `index.html` in een browser.
