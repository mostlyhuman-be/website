# Mostly Human — website

De one-page website van Mostly Human, een klein marketingbureau uit Mechelen.

Alles zit in één bestand: `index.html` (HTML, CSS en een paar regels JavaScript, geen build-stap).
De afbeeldingen (alien-logo en wordmark) staan in `assets/`.

## Online zetten

De site draait op GitHub Pages vanaf de `main`-branch, op het domein uit `CNAME` (mostlyhuman.be). Een push naar `main` zet de nieuwe versie online.

## Lokaal bekijken

Open `index.html` in een browser.
